# deepanshujindal.com

Personal website of Deepanshu Jindal, architect.

## Change links (SuperProf, Instagram, portfolio, email)

Open `index.html`. Near the top is a block called `window.SITE`. Put a link between the quotes and commit. An empty line (`''`) hides that button. Adding the SuperProf link adds a "Book a class" button.

## Change any text

Open `index.html`, click the pencil icon, find the sentence with Ctrl+F, edit it, then **Commit changes**. The site updates in about a minute.

## Replace the photo, CV or portfolio

Click **Add file → Upload files** and upload the new file with exactly the same name. It replaces the old one.

- `deepanshu-jindal.jpg` (portrait, about 900 × 1125 px)
- `Deepanshu-Jindal-CV.pdf`
- `Deepanshu-Jindal-Portfolio.pdf`

## Files
